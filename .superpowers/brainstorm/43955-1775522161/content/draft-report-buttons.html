Visibility Rules

Button Shows When
  • User is FOP (isPatron)
  • Pool is from a draft (draftShareId exists)
  • User is the pool owner
Button Hidden When
  • Not FOP
  • Sealed pool (no draft data)
  • Viewing someone else's pool
