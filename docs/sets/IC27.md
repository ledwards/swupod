## Overview

| Property | Value |
|----------|-------|
| Set Code | IC27 (swuapi) |
| Set Number | none — non-core product (`setNumber: 9` in config is the press era only) |
| Set Name | Icons 2027 Edition |
| Formats | **Chaos Sealed and Chaos Draft only** |
| Press | Block B (same rules as HMW) |
| Color | `#B8860B` |

Icons is not a numbered core set. It rotates nothing and is never drafted or
sealed on its own in PTP.

## How "Chaos only" is enforced

- **Registry.** `IC27_CONFIG` lives in `CHAOS_ONLY_SET_CONFIGS`, never
  `SET_CONFIGS`. Draft/Sealed/Rotisserie landings, rotation (`latest.ts`), the
  Play card pool, `/api/entry`, imports and stats all iterate `SET_CONFIGS`, so
  none of them see Icons. `getSetConfig('IC27')` still resolves it so packs print.
- **Server.** `getUnavailableSetReason` rejects chaos-only codes unless the
  caller passes `{ allowChaosOnly: true }`. Only Chaos Draft (`/api/draft` with
  `draftMode: 'chaos'`) does; Chaos Sealed never calls that gate. Pack Wars,
  Pack Blitz and Rotisserie reject `isChaosOnlySet` codes explicitly.
- **Client.** `fetchSets` lists IC27 only with `includeChaosOnly: true`, which
  only the Chaos Sealed / Chaos Draft pickers pass.

## Pack rules (differences from HMW)

- **Base slot prints Special bases** (`packRules.baseRarity: 'Special'`): Icons
  has no Common bases. No Hyperspace bases exist, so `baseToHyperspace` is 0.
- **Leader slot is all Common.** The two Special leaders are spotlight leaders,
  excluded from the leader slot like HMW's, but eligible for Showcase.
  With no Rare leaders, the woven 8+8 leader sheet doesn't apply; the spacing
  solver builds the sheet.
- **`baseLineAspectConflict: false`.** The woven base sheet is built from
  8-base chunks; with 4 single-aspect bases, plain aspect-adjacency dedup is
  the same rule.
- No prestige (`uc3ToPrestige: 0`).
- Commons auto-assign to Block B belts A/B (`commonBeltAssignments.ts`).
